### 💡 进阶写法（更可靠）

如果要求**批量输出多条记录**，推荐用 JSON Array + 明确约束：

```
请从以下护理内容中提取关键信息，严格按 JSON 格式输出，不要添加任何其他文字：

[
  {
    "操作名称": "静脉输液",
    "执行时间": "2026-07-15 14:30"
  }
]

要求：
1. 只输出 JSON，不要 Markdown 代码块标记
2. 执行时间格式统一为 YYYY-MM-DD HH:mm
3. 操作名称需简洁准确
```

### 🎯 关键点总结

| 技巧 | 说明 |
|------|------|
| **明确字段名** | 用中文键名，让输出可直接对接中文系统 |
| **给出示例** | 模型照葫芦画瓢，准确率大幅提升 |
| **禁止额外输出** | "不要添加任何额外解释"防止模型啰嗦 |
| **指定格式** | 时间格式、数组结构提前定义好 |
| **批量 vs 单条** | 单条用 `{}`，多条用 `[{},{}]` |
